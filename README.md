# SolonCode Studio

> ⚠️ **非官方项目** — 本项目是社区开发者开发与维护的基于 SolonCode CLI 第三方桌面工作台，**非 SolonCode 官方产品**。项目独立开发和发布，如有问题请在本仓库提 Issue。

[SolonCode CLI 官网](https://solon.noear.org/article/soloncode) | [SolonCode Studio 官网](https://soloncode.studio) | [下载最新版本](https://soloncode.studio) | [使用说明](https://soloncode.studio)

SolonCode Studio 是一个基于 Tauri 2 构建的轻量 SolonCode CLI 专属桌面工作台，统一管理 CLI 全生命周期，支持多工作区并行，一键访问 Web/CLI 操作界面。
